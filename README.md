## Projects

These are portfolio projects.

### STARK

A local-first RAG workspace for asking questions about your own documents. Retrieval is hybrid: a vector search and a BM25 search, merged by reciprocal rank fusion and reordered by a cross-encoder. It reads PDF, Word and Markdown files, images through OCR, audio through Whisper, and email and Slack exports. It runs on Ollama and ChromaDB locally, and on Groq and Pinecone when hosted.

[Live demo](https://stark-snowy.vercel.app/landing) and [source](https://github.com/ricardomadeira93/Stark). Built with Next.js, FastAPI, Python, ChromaDB, Pinecone and Ollama.

### Draft

An assistant that fills in RFPs and security questionnaires from a company knowledge base. Document retrieval and answer generation use LangChain, embeddings and Pinecone, with Groq in production and Ollama locally. CI/CD runs on GitHub Actions, deployed on Vercel and Render.

[Live demo](https://draft-pink.vercel.app) and [source](https://github.com/ricardomadeira93/Draft). Built with Next.js, FastAPI, Python, LangChain and Pinecone.
